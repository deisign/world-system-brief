WORLD SYSTEM BRIEF / EDITORIAL DESK

Review desk

Локальный редакторский интерфейс. Не подключается к сети и не публикует выпуск.

1. Загрузить черновик

Выбери три файла из research/drafts/YYYY-MM-DD/canonical/. Они читаются только в браузере.

Ожидание файлов.

2. Редакционные решения

Решение и комментарий обязательны для каждого кандидата. Источники открываются отдельной вкладкой для самостоятельной проверки.

3. Подтверждение выпуска

Файл следует сохранить как research/approvals/YYYY-MM-DD.json. Затем локально запустить node publisher/editorial-approval.js YYYY-MM-DD и создать PR с результатом. Это не публикация одним нажатием.
