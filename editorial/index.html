Review desk

Локальный редакторский интерфейс. Не подключается к сети и не публикует выпуск.

Выбор выпуска из GitHub

Загружает файлы из исследовательских PR репозитория deisign/world-system-brief. Для просмотра токен не нужен.

1. Загрузить черновик вручную

Выбери три файла из research/drafts/YYYY-MM-DD/canonical/. Они читаются только в браузере.

Ожидание файлов.

2. Редакционные решения

Решение и комментарий обязательны для каждого кандидата. Источники открываются отдельной вкладкой для самостоятельной проверки.

3. Подтверждение выпуска

Создать редакционный PR

После формирования решения можно отправить его в отдельную ветку и открыть Draft PR. Публикационный код и сайт эта операция не меняет. Нужен персональный fine-grained GitHub token с правами Contents: Read and write и Pull requests: Read and write только для этого репозитория. Токен используется в оперативной памяти страницы, не записывается в репозиторий и не сохраняется в браузере.

Файл следует сохранить как research/approvals/YYYY-MM-DD.json. Затем локально запустить node publisher/editorial-approval.js YYYY-MM-DD и создать PR с результатом. Это не публикация одним нажатием.
