# Physical Engraving — reviewed SVG handoff

WSB publishes **only a reviewed export of the real Draw Beautiful renderer**. No placeholder plate is generated by the publishing process, and no upstream rendering scripts run during deployment.

## Circus handoff

1. In `~/projects/draw-beautiful`, build the approved tanker Study 04 / profile 1.1 with the original `kit/intaglio.mjs`, keeping the fixed light and camera. Record `git rev-parse HEAD` from that original repository.
2. Export its actual SVG paths/viewBox to `visualizations/engravings/tanker-study-01/plate.svg` in the WSB working tree. Do **not** paste a screenshot into an SVG wrapper. Export the true vector geometry from the original engine. Use shapes/path outlines rather than remote assets.
3. Review the render in a desktop browser, mobile viewport, reduced-motion settings and at enlarged detail. Record the outcomes.
4. Create `visualizations/engravings/manifest.json`:
```json
{
  "engravings": [
    {
      "id": "tanker-study-01",
      "review_status": "reviewed",
      "engine_revision": "REPLACE_WITH_40_CHARACTER_UPSTREAM_COMMIT_SHA",
      "model_source": "https://github.com/bumicodes/draw-beautiful",
      "title": {
        "en": "Tanker study",
        "ua": "Дослідження танкера"
      },
      "caption": {
        "en": "Schematic tanker, engraved from the physical model at a fixed light angle.",
        "ua": "Схематичний танкер, гравірований із фізичної моделі за фіксованого освітлення."
      },
      "alt": {
        "en": "Three-quarter procedural engraving of a tanker with a bridge and cargo deck",
        "ua": "Процедурна гравюра танкера у три чверті з надбудовою та вантажною палубою"
      },
      "qa": {"desktop": true, "mobile": true, "reduced_motion": true, "closeup": true}
    }
  ]
}
```
5. Run `npm run build`. Build deliberately fails for missing data, missing reviewed SVG, unsafe SVG markup, incomplete language copy or unfinished QA. A manifest containing an empty engravings array publishes **no** physical plate.
6. Keep source `scene.mjs`, engraving profile and upstream MIT attribution alongside the export when committing; avoid embedding executable JavaScript. Interactive experimental scenes remain separate from the static publication asset.

**Distinct responsibilities:** Draw Beautiful produces physical engravings; `System Mechanism` produces analytical route and dependency diagrams. Neither is proof of a real tanker design or exact shipping corridor.
